To start the simulation: run main.py.
To close the simulation: click in the bottom right corner.

Note: UI elements are missing due to a bug in the current PyGame version.

Some additional (invisible) buttons are implemented at the top of the screen, starting from the top left corner to halfway to the right of the screen, which show:
- A creature overview of the current generation
- A neural network overview of the current best creature
- The isolated movement of the current best creature

These views can then be closed by clicking in the top left corner again.

Clicking in the top right corner saves the fitness history graph.
